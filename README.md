# Sales and Profit Dashboard

A Tableau dashboard built from an Excel orders dataset (51,290 rows).

## What it shows
- Sales by region, with profit as a line on a second axis
- Sales against profit for each product sub-category

## Findings
- Central has the highest sales (about 2.82M).
- Tables sell about 757K but make a loss, the only sub-category in the red.
